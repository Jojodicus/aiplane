Acme Corp support

This stand-in host page carries the croit AIplane chat widget. The red Comic Sans styling on buttons and paragraphs is the host's own: the widget in the corner must look unaffected.

The snippet

<script
  src="https://YOUR-GATEWAY/embed.js"
  data-agent-key="gwe_..."
  async></script>

The tag below targets a local mise run dev-ui gateway on http://127.0.0.1:8080 with the key it seeds. Serve this directory from http://localhost:8000 (the origin that key allows) and open it there: 

python3 -m http.server 8000 -d examples/embed

Optional attributes

data-lang="de"          language (default: the browser's)
data-theme="dark"       light | dark (default: follows the visitor's OS)
data-position="left"    left | right (default: right)
data-title="Ask Acme"   panel title (default: the agent's display name)

Colors and shape are CSS custom properties on the croit-aiplane-embed element, see below.
